# Anagata Warehouse frontend

React/Vite frontend untuk halaman utama Anagata Warehouse. Laravel menyediakan
konten CMS, lokasi, mitra pengiriman, metadata dan konfigurasi analytics.

Jalankan `npm ci` lalu `npm run build` di folder ini setelah mengubah source.
Hasil build tersimpan di `public/anagata-assets/`, sedangkan gambar bawaan ada di
`public/anagata-images/`. Ganti foto dan video referensi melalui CMS ketika aset
Anagata yang sudah disetujui tersedia.
